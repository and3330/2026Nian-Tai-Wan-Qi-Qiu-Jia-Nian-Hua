# 無障礙改善與驗證範圍

評估日期：2026-10-11  
目標：WCAG 2.2 A 與 AA；包含中文、英文、公開頁面與管理後台。  
**狀態：已完成本次程式改善及有限範圍驗證，尚不可宣稱整站完全符合或取得認證。**

## 依據與參考專案

- 正式依據：[W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)。AA 必須滿足全部適用的 A、AA 成功準則，且適用於完整頁面與完整交易流程，不只元件或首頁。
- 實作參考：[plugin87/ux-ui-agent-skills](https://github.com/plugin87/ux-ui-agent-skills/tree/main/accessibility) 的檢查清單、ARIA、視覺與認知指引。該專案含部分 AAA／建議實務，不把它們誤列為 AA 強制要求；例如 Focus Appearance 2.4.13 是 AAA。
- [ALTCHA](https://github.com/altcha-org/altcha) 是防機器人驗證元件，其無障礙聲明不等於採用網站的合規聲明。本網站目前沒有 CAPTCHA，不因本次改善額外增加驗證挑戰或安裝該套件。
- IAAP 專業人員資格與網站符合性是不同事項。本文件不是 IAAP 認證、第三方認證或正式合規證明。

## 必須保留的產品行為

- 中英文切換不清空購票表單、查詢輸入或購物車。
- 不改票價、名額計算、付款／退款狀態、角色權限或寄信條件。
- 原 Banner 圖檔依既有要求保留，但圖片文字仍需逐張檢驗 1.1.1 與 1.4.5；保留圖片不構成自動豁免。
- 不以障礙輔助浮層、整頁 DOM 自動補標籤、刪除功能或隱藏失敗項目冒充原始碼修正。
- 測試不執行真實付款、退款、發票開立、寄信、刪除或修改訂單。

## 55 項 A／AA 準則驗收清單

以下是完整验收清單，不是「55 項全部通過」的聲明。每項需依頁面、狀態及流程取證。
「自動＋人工」表示自動化只能檢查部分條件；沒有 axe 違規仍不能直接填為通過。

| 準則 | 等級 | 驗證方法／本專案的必要驗收 |
|---|---|---|
| 1.1.1 非文字內容 | A | 自動＋人工：圖片、Banner、QR、商品圖、圖示控制的文字替代及正確內容 |
| 1.2.1 預錄純音訊／純視訊 | A | 人工：盤點現有及後台新增媒體；沒有適用媒體才能列不適用 |
| 1.2.2 預錄字幕 | A | 人工：所有帶音訊的預錄影片具同步且正確字幕 |
| 1.2.3 預錄口述影像或媒體替代 | A | 人工：視覺資訊的完整替代，不以短 alt 取代影片內容 |
| 1.2.4 即時字幕 | AA | 人工：若有直播需提供；目前路由未發現直播播放器，仍須內容盤點 |
| 1.2.5 預錄口述影像 | AA | 人工：影片重要視覺內容的口述影像 |
| 1.3.1 資訊與關係 | A | 自動＋人工：標題、label、表頭、群組、對話框名稱、錯誤關聯 |
| 1.3.2 有意義的順序 | A | 人工：CSS 線性化與螢幕閱讀器閱讀順序 |
| 1.3.3 感官特徵 | A | 人工：不只用颜色、形狀、方位指示操作 |
| 1.3.4 顯示方向 | AA | 人工：手機直向／橫向不鎖定，功能不流失 |
| 1.3.5 識別輸入目的 | AA | 自動＋人工：姓名、電話、email 與登入 autocomplete |
| 1.4.1 色彩使用 | A | 人工：狀態、選取、圖表不只依顏色區分 |
| 1.4.2 音訊控制 | A | 人工：無不可控制的自動音訊；外部媒體亦需檢查 |
| 1.4.3 最低對比 | AA | 自動＋人工：一般字 4.5:1、大字 3:1；含 hover、disabled 例外與圖片背景 |

| 1.4.10 重排 | AA | 自動＋人工：320 CSS px／400% zoom，資料表可區域捲動但頁面不可因表格橫向溢出 |
| 1.4.11 非文字對比 | AA | 人工：輸入邊界、圖示、選取與焦點可辨識，至少 3:1（適用時） |
| 1.4.12 文字間距 | AA | 人工：行高 1.5、段距 2em、字距 .12em、詞距 .16em 不截字或遮擋 |
| 1.4.13 懸停／焦點內容 | AA | 人工：tooltip 可關閉、可移入、持續顯示 |
| 2.1.1 鍵盤操作 | A | 人工：導覽、下拉、日期、表單、對話框、POS、掃碼替代操作皆可用鍵盤 |
| 2.1.2 無鍵盤陷阱 | A | 人工：對話框正確循環、Esc 關閉並返回開啟者；非對話框可正常離開 |
| 2.1.4 字元快捷鍵 | A | 原始碼＋人工：若有單字元快捷鍵，需關閉／重設／僅焦點內啟用 |
| 2.2.1 計時可調 | A | 原始碼＋人工：目前應用登入工作階段 7 天；金流提供商期限需另外檢驗，不推定豁免 |
| 2.2.2 暫停、停止、隱藏 | A | 人工：倒數、名額／統計輪詢可暫停；非必要持續動畫可停止 |
| 2.3.1 閃爍不超閾值 | A | 人工：動畫與未來上傳媒體沒有超閾值閃爍 |

| 2.4.6 標題與標籤 | AA | 自動＋人工：heading 層級與名稱具意義，不只避免掃描警告 |

| 2.5.2 指標取消 | A | 原始碼＋人工：重要操作不在按下階段不可逆觸發 |

| 3.1.1 頁面語言 | A | 自動：中文 zh-TW／英文 en 與切換同步 |

| 3.2.3 一致導覽 | AA | 人工：各頁導覽順序與位置一致 |

| 3.3.1 錯誤識別 | A | 自動＋人工：錯誤文字、aria-invalid／describedby、讀屏宣布及首個錯誤焦點 |

| 3.3.3 錯誤建議 | AA | 人工：已知錯誤提供具體修正方法，不只「失敗」 |

## 尚不能被自動掃描取代的驗證

1. NVDA + Firefox／Chrome、VoiceOver + Safari 的實際讀屏操作，尤其購票、查詢、退款資料、POS 與掃碼替代流程。
2. 真正瀏覽器 200% 縮放、400% 重排、文字間距、高對比與手機橫向。
3. 訂單有資料／無資料、失敗、載入、停用、巢狀對話框、每個角色可見功能，不能只驗初始頁面。
4. 未開放報名、無有效退款連結等無法抵達的分支，需要安全測試資料和受控環境，不得為測試修改正式訂單。
5. 金流商託管頁面與其他第三方服務的完整交易、計時與錯誤復原。本站程式無法直接修正對方網站。
6. 每張 Banner／活動海報的文字資訊、文字影像例外、未來新增 CMS 內容與媒體品質。

若任一適用準則失敗或重要流程未驗證，維持「尚未確認完全符合」；不得用百分比分數、零自動違規或套件聲明代替整站符合性結論。
